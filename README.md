# Urban Store

## Descripción

Urban Store es una página web de una tienda de ropa y accesorios. El proyecto fue desarrollado utilizando HTML y CSS, con el objetivo de crear una interfaz moderna, atractiva y fácil de navegar.

La página permite conocer la tienda, explorar una colección de productos y consultar información de contacto.

El diseño está inspirado en páginas modernas de tiendas de moda, utilizando una combinación de secciones visuales, tarjetas de productos, efectos al pasar el mouse y un diseño adaptable a diferentes tamaños de pantalla.

## Objetivo

Crear una página web para una tienda de ropa y accesorios, aplicando los conocimientos de HTML y CSS para organizar la información y desarrollar una interfaz visual moderna y agradable para los usuarios.

## Estructura del proyecto

El proyecto está compuesto por los siguientes archivos:

- `index.html`: Página principal de Urban Store.
- `productos.html`: Página donde se muestra la colección de productos.
- `nosotros.html`: Página con información de la tienda, historia, valores y datos de contacto.
- `estilo.css`: Archivo que contiene los estilos utilizados en las páginas.
- `README.md`: Documento con la información y descripción del proyecto.

## Productos

La tienda cuenta con diferentes productos, entre ellos:

1. Inicio

3. Nosotros

## Diseño

El diseño de Urban Store utiliza una estética moderna inspirada en tiendas de moda y páginas editoriales.

Se utilizan principalmente:

- Fondos claros y oscuros.
- Color rojo como color de acento.
- Tipografía moderna.
- Secciones de gran tamaño.
- Tarjetas visuales para los productos.
- Efectos de movimiento al pasar el cursor.
- Diseño adaptable para dispositivos móviles.
- Navegación sencilla entre las diferentes páginas.

## Características

El proyecto incluye:

- Página de inicio con presentación de la tienda.

## Cómo ejecutar el proyecto

1. Descargar o copiar la carpeta del proyecto.

2. Abrir la carpeta `dsw1-50` en Visual Studio Code.

3. Verificar que todos los archivos estén dentro de la misma carpeta.

4. Abrir el archivo `index.html`.

5. Ejecutarlo en un navegador web.

También se puede utilizar la extensión **Live Server** de Visual Studio Code para visualizar los cambios automáticamente mientras se desarrolla el proyecto.
